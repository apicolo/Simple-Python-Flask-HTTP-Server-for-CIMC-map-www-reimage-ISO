# Simple-Python-Flask-HTTP-Server-for-CIMC-map-www-reimage-ISO
Simple Python+Flask HTTP Server for CIMC map-www reimage ISO

- Dependency : python (```pip install python```)
- Dependency : flask (```pip install flask```)

Running this script it start a HTTP server on port 80 on all interfaces. (you may modify http port 80 to other ports if blocked by firewall).

A folder named "iso_share" will be created, all ISOs or files served by HTTP server should be placed inside this folder.

To run it:

```python cimc_http_server_v2.py```

or

```python3 cimc_http_server_v2.py```
